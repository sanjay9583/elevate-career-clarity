# Elevate Career Clarity

A 5-day domain bootcamp landing page by CollegeHive — structured exposure to industry experts, HRs, and recently placed graduates.

**Live URL:** https://careers.collegehive.in

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- Deployed via GitHub Pages

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
