──────────────────────────────────────
3. ACCENT COLOR — THE STAR
──────────────────────────────────────

Name:            Terracotta / Warm Burnt Coral
HSL:             16, 65%, 48%
Hex:             #C96832
RGB:             201, 104, 50
Used for:        CTA buttons, badges, section labels,
                 check icons, ring focus, hover accents,
                 floating FAB

This is NOT a typical AI blue/purple. It's warm,
earthy, Indian-feeling, and distinctive.

4. TYPOGRAPHY
──────────────────────────────────────

BODY FONT:
  Family:          Inter
  Import:          fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700
  Weights used:    300 (light), 400 (regular), 500 (medium), 600 (semibold), 700 (bold)
  Usage:           All body text, nav links, buttons, form labels

DISPLAY / HEADING FONT:
  Family:          Source Serif 4
  Import:          fonts.googleapis.com/css2?family=Source+Serif+4:ital,wght@0,400;0,600;0,700;1,400
  Weights used:    400 (regular), 600 (semibold), 700 (bold), 400 italic
  Usage:           Section h2/h3 headings, hero headline, CTA headlines
  Tailwind class:  font-serif

TAILWIND CONFIG:
  fontFamily: {
    sans: ["'Inter'", "system-ui", "sans-serif"],
    serif: ["'Source Serif 4'", "Georgia", "serif"],
  }

──────────────────────────────────────
9. ANIMATIONS
──────────────────────────────────────

SCROLL REVEAL (CSS + IntersectionObserver):
  • .reveal          → translateY(32px) → 0, opacity 0 → 1
  • .reveal-scale    → scale(0.95) → 1, opacity 0 → 1
  • .reveal-fade     → opacity 0 → 1
  • .stagger-1..6    → animation-delay 0.05s increments
  • Easing:          cubic-bezier(0.22, 1, 0.36, 1) — "out expo"
  • Duration:        0.6–0.8s
  • Trigger:         once, threshold 0.1–0.2

CTA PULSE:
  .pulse-cta → box-shadow pulse with accent color, 2.5s infinite

BADGE DOT:
  animate-pulse (Tailwind built-in) on the bootcamp badge dot


──────────────────────────────────────
10. ICON SYSTEM
──────────────────────────────────────

Library:          Lucide React (lucide-react)
Size:             12–16px for inline, inside 9×9 (w-9 h-9) tinted containers
Tint pattern:     bg-accent/10 container + text-accent icon
Check marks:      Check icon, text-accent, size 15

Speaker avatars (when no photo):
  Initials in 16×16 (w-16 h-16) circle
  Each speaker gets a unique soft color:
    amber-100/amber-700, rose-100/rose-700, blue-100/blue-700,
    emerald-100/emerald-700, violet-100/violet-700, orange-100/orange-700


──────────────────────────────────────
11. CSS CUSTOM PROPERTIES FILE
──────────────────────────────────────

File: src/index.css

This is the single source of truth for all colors.
Every component uses hsl(var(--token)) via Tailwind,
so changing the CSS variables changes the entire site.
